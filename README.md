# Aditi Interiors — Luxury Interior Design Studio Website

A bespoke, responsive, and high-performance website crafted for **Aditi Interiors**, faithful to the client's reference design with interactive features, fluid organic layouts, and high-end aesthetics.

---

## 🌟 Key Highlights & Design Elements

- **Pixel-Accurate Brand Identity**:
  - Exact logo icon integration (`A` with vibrant lime-olive `i`).
  - Editorial typography: *Playfair Display* & *Cormorant Garamond* for timeless serif elegance, paired with *Caveat* script for artistic cursive accents ("*Homes*", "*Dream Space*").
  - Organic dark olive corner tab anchoring the brand mark.
  - Signature warm linen & alabaster palette (`#FAF7F2`) with forest olive (`#1E2719`) and olive-lime accents (`#8FA83C` / `#96B842`).

- **Hero Experience**:
  - Sculptural fluid organic curved frame matching the reference mockup.
  - Interactive 3-slide gallery featuring the signature curved bouclé sofa living room, master suite, and architectural dining space.
  - Foreground botanical leaf overlay for layered depth.
  - Dual CTAs: *Explore Projects →* and *Get a Quote*.

- **Value Proposition Bar**:
  - 4 clean pillars with fine architectural dividers:
    1. **Residential Interiors**
    2. **Commercial Interiors**
    3. **Turnkey Solutions**
    4. **Space Consultation**

- **About Us Section**:
  - Layered card composition with the modern sculptural branching light fixture.
  - Offset olive green backing card and decorative petal accent.
  - 3 Core Pillars: *Creative Designs*, *Quality Execution*, and *Client-Centric Approach*.
  - Grand watermark monogram **Ai** in translucent background.

- **Our Projects Portfolio**:
  - Category filter pills: `All`, `Living Room`, `Bedroom`, `Modular Kitchen`, `Commercial`.
  - Responsive project cards with authentic reference visuals and circular arrow buttons `( → )`.
  - Interactive Lightbox & Project Detail Modal with specifications (Area, Location, Duration, Key Materials, and "Inquire About Similar Design" action).

- **Interactive Before & After Transformation Slider**:
  - Draggable touch-friendly slider comparing bare shell construction with completed luxury interior.

- **Interactive Interior Cost Estimator & Quote Calculator**:
  - Step-by-step calculator for 1 BHK, 2 BHK, 3 BHK, 4 BHK/Villa, and Commercial Offices.
  - Dynamic estimated investment calculation in Lakhs INR with duration.
  - One-click **WhatsApp direct link** pre-formatted with the client's selected space and tier!

- **"Let's Design Your Dream Space" Bottom Banner**:
  - Forest olive rounded container with botanical leaf watermark.
  - Cursive gold script accent.
  - Direct "Get a Free Consultation" WhatsApp action.

- **Client Testimonials & Complete Studio Footer**:
  - Real homeowner reviews, studio addresses (Bangalore & Mumbai), social links, and phone numbers.
  - Pulsing Floating WhatsApp quick chat button with tooltip.

## 🚀 How to Run the Website

### Option 1: Direct File Opening
Simply double-click `index.html` to open it in any modern web browser (Chrome, Edge, Safari, Firefox).

### Option 2: Using Node / NPM
```bash
npm start
# OR
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Option 3: Python Web Server
```bash
python -m http.server 3000
```
Then visit [http://localhost:3000](http://localhost:3000).
